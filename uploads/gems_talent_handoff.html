GEMS Talent — Full Project Handoff

Singapore talent agency · Desktop-first editorial prototype · React 18 + Babel CDN · Inline JSX

Overview

GEMS Talent is a Singapore entertainment marketing & event logistics agency (founded 2014). The prototype is a multi-page React-in-HTML site built with React 18 + Babel via CDN, inline JSX modules, and vanilla CSS. Design direction: editorial restraint inspired by WME. A Tweaks panel provides live design controls with JSON persistence.

Nav decisions done

Always mist bg at all scroll positions. Condensed state: opaque mist + internal top→bottom gradient (0.98→0.86 alpha) + blur. No external gradient strip below nav. Logo: company stamp + "TALENT" only (GEMS removed — stamp already contains it). Footer is a 3-column grid (Studio links, real pages; Reach = mailto/tel; Journal link removed).

Button wiring done

  • ARoster cards → artistes.html#{slug} · Work cards → work.html#{slug}
  • B"See full roster" → artistes.html · "All projects" → work.html · "Submit a brief" → contact.html#brief
  • CDuplicate Studio column removed · 3-col footer grid · Studio links resolve to real pages
  • DEnquiry form: "Send an enquiry" / "Send enquiry →" · controlled inputs · Phone (optional) · thank-you state · id="brief"

Email system — Resend done

Free tier: 3,000 emails/mo (~1,500 enquiries). No card required. Two emails per form submit: team notification to talent@gems.sg (Reply-To = enquirer) + auto-reply to enquirer echoing their message. Email Tweaks panel has 3 axes: Voice (editorial/warm/crisp), Composition (editorial/minimal/display), Brand bar (cobalt/bone/ink). Ink preset: mist header, stamp + "· TALENT" wordmark, cobalt-deep receipt card. Persisted defaults: voice=editorial, composition=editorial, header=ink.

Production caveat: assets/gems-stamp-nav.jpg is a relative path in email templates — must be replaced with an absolute public URL before going live. email-preview.html uses a <base href> workaround for local preview only. Full setup guide in EMAIL_SETUP.md.
